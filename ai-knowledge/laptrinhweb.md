## 2. Mô tả môn học

Môn học Lập trình Web cung cấp cho sinh viên kiến thức nền tảng và kỹ năng xây dựng ứng dụng web. Sinh viên được học về HTML, CSS, JavaScript, frontend framework, backend API, cơ sở dữ liệu và triển khai ứng dụng web.

Sau khi hoàn thành môn học, sinh viên có thể xây dựng một website hoặc ứng dụng web cơ bản có giao diện người dùng, xử lý nghiệp vụ phía backend và lưu trữ dữ liệu.

## 4. Mục tiêu môn học

Sau khi học xong môn học, sinh viên có thể:

- Hiểu được kiến trúc cơ bản của một ứng dụng web.
- Sử dụng HTML, CSS, JavaScript để xây dựng giao diện web.
- Hiểu cách frontend giao tiếp với backend thông qua API.
- Xây dựng backend đơn giản bằng Node.js/Express hoặc công nghệ tương đương.
- Kết nối ứng dụng web với cơ sở dữ liệu.

- Biết kiểm thử và triển khai ứng dụng web cơ bản.

## 9. Lỗi thường gặp khi học môn này

### Không hiểu cách frontend gọi backend

Nguyên nhân:
- Chưa nắm rõ client-server.
- Chưa hiểu HTTP method như GET, POST, PUT, DELETE.
- Chưa hiểu JSON.

Cách xử lý:
- Ôn lại REST API.
- Thực hành gọi API bằng Postman.
- Tạo ví dụ nhỏ frontend gọi API đơn giản.

### Giao diện bị vỡ layout

Nguyên nhân:
- Chưa hiểu CSS box model.
- Chưa dùng đúng flexbox/grid.
- Chưa kiểm tra responsive.

Cách xử lý:
- Dùng DevTools để kiểm tra CSS.
- Chia layout thành các khối nhỏ.
- Test trên nhiều kích thước màn hình.

### Backend không kết nối được database

Nguyên nhân:
- Sai connection string.
- Database chưa chạy.
- Sai username/password.
- Chưa xử lý async/await đúng cách.

Cách xử lý:
- Kiểm tra lại biến môi trường.
- Kiểm tra database service.
- Log lỗi kết nối ở backend.
- Test kết nối bằng script nhỏ.

## 10. Câu hỏi thường gặp

### Sinh viên cần biết gì trước khi học môn Lập trình Web?

Sinh viên nên có kiến thức cơ bản về lập trình, biến, hàm, mảng, object và cơ sở dữ liệu. Nếu chưa chắc HTML/CSS/JavaScript, sinh viên nên ôn lại trước khi học React hoặc backend.

### Môn này có cần làm project không?

Có. Sinh viên nên làm project nhỏ hoặc project nhóm để vận dụng kiến thức frontend, backend và database.

### Nên học frontend hay backend trước?

Sinh viên nên học frontend cơ bản trước để hiểu giao diện và tương tác người dùng, sau đó học backend để hiểu API và xử lý dữ liệu.

### Nếu không hiểu bài thì nên làm gì?

Sinh viên nên xem lại tài liệu, chạy lại ví dụ trên lớp, hỏi giảng viên, trao đổi trong box chat lớp học và thực hành thêm bài tập nhỏ.
